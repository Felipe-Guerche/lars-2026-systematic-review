# Data

All public tables use English field names and controlled labels. Publication titles, author names, DOI values, and evidence quotations remain faithful to the source records.

- `studies.csv`: 38 full-text records and screening status.
- `search/`: search strings, yields, and sanitized Zotero-import metadata.
- `screening/`: available record-level decisions.
- `extraction/study_extraction.csv`: 35 included studies and evidence fields.
- `extraction/taxonomy_membership.csv`: auditable taxonomy subset used by the taxonomy tables and figures.
