# Study-level extraction

`study_extraction.csv` is the canonical 46-row extraction table (35 original studies plus 11 included in the
supplementary open-access retrieval round, August 2026). It uses English column names and controlled labels,
while evidence quotations remain source-faithful. The Patton2024 interface-detail field was completed from
the source PDF because it was blank in the working CSV. `taxonomy_membership.csv` is a compact audit view of
the classification variables used in the taxonomy figures.

The taxonomy figure crosses symbolic structure (none, lightweight/static, or formal) with autonomous
feedback. In the 46-study corpus no cell is empty: Group D spans all three feedback cells (see
`docs/taxonomy_audit.md` for the per-study basis and the 2026-08-06 adjudications).
