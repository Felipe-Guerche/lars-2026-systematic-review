# Study-level extraction

`study_extraction.csv` is the canonical 35-row extraction table. It uses English column names and controlled labels, while evidence quotations remain source-faithful. The Patton2024 interface-detail field was completed from the source PDF because it was blank in the working CSV. `taxonomy_membership.csv` is a compact audit view of the classification variables used in the taxonomy figures. The figure crosses symbolic structure (none, lightweight/static, or formal) with autonomous feedback; empty cells indicate no included studies.
