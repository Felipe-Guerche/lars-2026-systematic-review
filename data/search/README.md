# Search archive

`search_strings.md` contains the nine database-specific queries. `database_yields.csv` contains the query-level counts used by the manuscript. `imported_records.csv` is a sanitized export of the Zotero query files: 98 imported rows, 69 unique DOIs, and 71 unique titles.

The imported Zotero rows are not raw database dumps and are not used to replace the 183-record PRISMA count.
